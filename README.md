#### 简介
基岩版自动整理行为包，启用功能后打开容器即可自动整理。

支持:2种整理方法，2种整理方向，手动键入命令整理
#### 下载
[下载最新版](https://gitee.com/ykxyx666_admin/sorter-be/releases/latest)
#### 使用方法：
1. 实验性游戏内容，开启测试版API，并且加上行为包。
2. 进入游戏，聊天发送".sorter"(注意打点)，然后立即退出聊天界面(0.5s内)，即可在弹出UI中开启自动整理。
3. 对着容器，发送.r，可以手动整理；对着空气，发送.r可以整理背包

#### 温馨提示:
漏斗不会被自动整理，只能输入.r手动整理，不用担心你的分类机被搞坏了。
